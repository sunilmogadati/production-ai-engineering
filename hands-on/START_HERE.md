## 👨‍🎓 I'm a Student (First Time Setup)

Follow these steps **in order**:

1. **[QUICK_START.md](QUICK_START.md)** (5 min)
   - Get API key
   - Install packages
   - Run first script

2. **Try a prompt script** (2 min)
   ```bash
   python prompt01_hello_world.py
   ```

3. **Start the server** (1 min)
   ```bash
   uvicorn serve:app --reload
   ```

4. **Open the dashboard** (1 min)
   - Open http://127.0.0.1:8000
   - Click on a prospect card to see details

**That's it!** You're ready for the first session.
